<h1>Negotiation Strategy Report – Consultant Role: TechNova IT Consulting Ltd.</h1>

<h2>Strategy Point 1: BATNA, Reservation Value and ZOPA</h2>

<ul>
    <li><strong>BATNA:</strong> Pursue alternative private-sector or education clients at standard rates or reallocate project capacity.</li>
    <li><strong>Reservation Value:</strong> Approx. £75,000 value (structured), with a hard price floor near £70,000.</li>
    <li><strong>ZOPA:</strong> No overlap on price alone (client ~£50k vs consultant ~£70k+), requiring structural solutions such as phasing or scope adjustment.</li>
</ul>

<h2>Strategy Point 2: Multi-Issue Options</h2>

<ul>
    <li><strong>Option A:</strong> Phased delivery (core £50k + enhancements £35k).</li>
    <li><strong>Option B:</strong> Reduced scope at £50k (core only, limited training).</li>
    <li><strong>Option C:</strong> Payment flexibility (£50k upfront + remainder spread).</li>
    <li><strong>Option D:</strong> Pilot project (£30–40k initial system).</li>
    <li><strong>Option E:</strong> Partnership model with future contract.</li>
</ul>

<h2>Strategy Point 3: Interests and Questions</h2>

<h3>Consultant Interests</h3>
<ul>
    <li>Sustainability</li>
    <li>Quality</li>
    <li>Reputation</li>
    <li>Long-term growth</li>
</ul>

<h3>Client Interests</h3>
<ul>
    <li>Affordability</li>
    <li>Functionality</li>
    <li>Minimal disruption</li>
</ul>

<h3>Key Questions</h3>
<ul>
    <li>What is essential in phase one?</li>
    <li>How flexible is funding?</li>
    <li>What defines success?</li>
</ul>

<h2>Strategy Point 4: Value-Based Anchoring</h2>

<ul>
    <li>Break down £75k into components (development, workflows, training).</li>
    <li>Frame price in terms of long-term value and efficiency gains.</li>
</ul>

<h2>Strategy Point 5: Package Options</h2>

<ul>
    <li><strong>Essential (£50k):</strong> core only.</li>
    <li><strong>Standard (£70–75k):</strong> core + reporting + training.</li>
    <li><strong>Premium (£85k):</strong> full solution + support.</li>
</ul>

<h2>Strategy Point 6: Conditional Concessions</h2>

<ul>
    <li>If phased delivery, then lower upfront cost</li>
    <li>If reduced scope, then maintain budget</li>
    <li>If follow-on work, adjust initial fee</li>
</ul>

<h2>Strategy Point 7: Objective Criteria</h2>

<ul>
    <li>Use market benchmarks (£80k–£100k typical).</li>
    <li>Reference industry practices (phased delivery, modular pricing).</li>
</ul>

<h2>Strategy Point 8: Sequencing (Power of Four)</h2>

<ol>
    <li>Start with goals</li>
    <li>Clarify priorities</li>
    <li>Present options</li>
    <li>Return to price</li>
</ol>

<h2>Strategy Point 9: Risk Management</h2>

<ul>
    <li>Define scope clearly</li>
    <li>Include change control</li>
    <li>Align expectations</li>
    <li>Confirm decision authority</li>
</ul>

<h2>Strategy Point 10: Relationship Strategy</h2>

<ul>
    <li>Position as long-term partnership</li>
    <li>Offer symbolic concessions</li>
    <li>Maintain collaborative tone</li>
</ul>
